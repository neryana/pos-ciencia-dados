# Pós-graduação em Ciência de Dados e Analytics

Este repositório contém trabalhos realizados na pós-graduação Ciência de Dados e Analytics, da Pontifícia Universidade Católica do Rio de Janeiro (PUC-Rio) em 2025.

Os trabalhos referentes a cada etapa dessa pós (dividida em "sprints") estão organizados em pastas, as quais contêm os respectivos MVP - Minimum Viable Product (Produto Mínimo Viável) e outros arquivos da etapa correspondente.
