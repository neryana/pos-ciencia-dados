# pos-ciencia-dados-analytics 
Repositório Ciência de Dados
Este repositório contém os trabalhos realizados na pós-graduação Ciência de Dados e Analytics da PUC - Rio, realizados em 2025. 

Os trabalho referentes a cada etapa dessa pós (dividida em "sprints") estão organizados em pastas, as quais contêm os respectivos MVP - Minimum Viable Product (Produto Mínimo Viável) e outros arquivos da etapa correspondente.
