# Pós-graduação em Ciência de Dados e Analytics

Este repositório contém os trabalhos realizados na especialização em Ciência de Dados e Analytics, realizada na Pontifícia Universidade Católica do Rio de Janeiro (PUC-Rio) em 2025.
Os trabalho referentes a cada etapa dessa pós (dividida em "sprints") estão organizados em pastas, as quais contêm os MVP - Minimum Viable Product (Produto Mínimo Viável) e outros arquivos relacionados a sua respectiva etapa.
